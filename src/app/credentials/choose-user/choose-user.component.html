Bienvenido a PetsCop

Inicia registrándote como alguno de los 3 usuarios que tenemos disponibles, cada uno con diferentes funcionalidades. Elige el que te convenga más.

USUARIO NORMAL
Como usuario normal podrás ver los posts, crear posts, comentar, responder comentarios, entre muchas cosas más.
USUARIO LOCAL
Como usuario local podrás decirnos donde se encuentra tu local, crear, visualizar posts, dar a conocer el horario de atención y mucho más.
USUARIO SERVICIO
Como usuario de servicio, podrás contarnos que tipo de servicio ofreces, crear, visualizar posts, dar a conocer el horario de atención y mucho más
